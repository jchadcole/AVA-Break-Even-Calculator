AVA containment break-even

Inbound calls take one of four paths: direct to an agent, contained in the IVR, contained in AVA, or IVR to AVA to an agent. This finds the share of calls AVA must contain before agent savings cover what AVA costs, and shows savings as containment grows. Values are examples until you replace them.

Every step below uses your current inputs. A spreadsheet that recomputes everything is here, so you can redo each line on a calculator or in a spreadsheet.

    How it is calculated
    • Handle hours per FTE per month = paid hours × % of time on these calls × occupancy. This is the time one FTE actually spends talking to callers.
    • Agent hours automated = calls contained in AVA × average call time ÷ 3600
    • FTEs saved = agent hours automated ÷ handle hours per FTE
    • Labor saved = FTEs saved × fully loaded agent cost
    • Net savings = labor saved − AVA per-call cost − AVA platform fee − implementation ÷ months
    • FTEs needed for non-automated calls = (direct % + IVR → AVA → Agent %) × calls × call time ÷ 3600 ÷ handle hours per FTE, rounded up when rounding to whole people.
    • From headcount: inbound calls = FTEs today × handle hours per FTE × 3600 ÷ call time ÷ (direct % + % reaching AVA)
    • Agent calls per hour = 3600 ÷ call time × occupancy; agent cost per call = agent cost ÷ (handle hours per FTE × 3600 ÷ call time)

    The comparison point is the same flow without AVA, where every call that leaves the IVR goes to an agent. Break-even is the lowest AVA containment where monthly cost is at or below that figure. IVR cost is the same on both sides, so it never moves the break-even.
